# Tingyi Cai’s academic homepage

Personal academic website: https://ca1man-2022.github.io/

## Content

- `_pages/about.md`: English introduction, selected publications, recent news and academic service.
- `_pages/chinese.md`: Chinese introduction and selected research.
- `_pages/news.md`: archived updates.
- `_publications/`: publication metadata and summaries. Set `selected: true` to feature a paper on the homepage.
- `_config.yml`: site metadata and sidebar profile.

## Local preview

Install Ruby and Bundler, then run:

```sh
bundle install
bundle exec jekyll serve --livereload
```

Review the English and Chinese pages, publication links and mobile layout before publishing. The repository’s existing GitHub Pages configuration controls deployment; a local edit does not change the live site.
